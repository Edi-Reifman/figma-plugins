Установка

Установить за минуту

Порядок одинаковый для всех четырёх плагинов. Нужно только настольное приложение Figma для Mac или Windows.

Скачайте архив

Нажмите «Скачать» у нужного плагина и распакуйте ZIP.

Положите папку на место

Выберите постоянное место, например «Документы/Figma plugins». Figma запускает плагин прямо из этой папки.

Импортируйте в Figma

Откройте любой файл в приложении Figma и пройдите по меню:

Plugins → Development →
Import plugin from manifest…

Выберите manifest.json

Файл лежит в распакованной папке. После этого плагин появится в меню:

Plugins → Development
Не работает в браузереИмпорт из manifest есть только в приложении Figma. Скачать его можно на figma.com/downloads.
Не перемещайте папкуЕсли удалить или переместить папку, плагин пропадёт из меню. Тогда просто импортируйте его заново.
ОбновлениеЗакройте плагин и замените файлы в той же папке новыми. Наборы и пресеты сохранятся.
