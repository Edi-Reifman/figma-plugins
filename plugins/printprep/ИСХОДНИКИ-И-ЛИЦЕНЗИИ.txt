PrintPrep 0.5.1-rc.1

Исходники PrintPrep включены в src/, build.cjs, configure-release.cjs,
release-check.cjs и tests/. Совместная сборка распространяется под GNU AGPLv3.
Полный текст лицензии: LICENSE.

EPS: Ghostscript 10.08.0, сборка @wasm-zoo/ghostscript 0.7.2, AGPL-3.0-or-later.
Оригинальные gs-core.js и gs-core.wasm не изменялись. Адаптер плагина:
src/eps-worker.js. Метаданные сборки, хеши, лицензии и сведения о происхождении
находятся в vendor/ghostscript/.

Сборка PrintPrep без сети: node build.cjs. Проверки: npm test.
Для пересборки самого Ghostscript нужны исходники и инструменты, указанные выше.
Весь архив PrintPrep-source должен оставаться доступным пользователям публичной
версии. Перед публикацией URL архива записывается через configure-release.cjs.

ICC-профили: vendor/icc/. Официальные default_cmyk.icc (общий SWOP) и
default_rgb.icc (sRGB, переименован в srgb.icc) из того же релиза Ghostscript.
Ссылки и сведения: vendor/icc/README.txt. Профили не изменялись.
Профиль пользователя не сохраняется в исходниках и не отправляется в сеть.

Упаковка runtime для лимита Figma 15 МБ:
Ghostscript WASM сжат Brotli без потерь и закодирован безопасным ASCII91.
Распаковка выполняется локально в export Worker. Восстановленные байты совпадают
с оригинальной сборкой Ghostscript; исходный бинарный файл не изменялся.
Распаковщик: brotli-compress 2.2.2, только pure-JS js.cjs, MIT (Google),
с дополнительными Apache-2.0 notices пакета. Лицензии: vendor/brotli/.
Исходники: https://github.com/kyr0/brotli-compress/tree/7e633f31b83e7d522fc2ff7c21905d30e82eab71
Загрузки runtime из сети нет. Размер загружаемого кода фиксирует build-size.json.
