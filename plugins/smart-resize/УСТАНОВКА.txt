УСТАНОВКА
1. Распакуйте архив и положите папку в постоянное место (не в «Загрузки», которые вы чистите) — Figma читает файлы плагина оттуда.
2. Откройте файл в настольном приложении Figma (в браузерной версии импорт не работает).
3. Меню Plugins → Development → Import plugin from manifest…
4. Выберите manifest.json из этой папки.
5. Запуск: Plugins → Development → название плагина.

ОБНОВЛЕНИЕ
Закройте плагин и замените файлы в этой же папке новыми. Настройки и пресеты сохранятся.
